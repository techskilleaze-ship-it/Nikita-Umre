# Nikita Umre — Portfolio

Personal portfolio website for Nikita Umre, Digital Marketing Professional (Nagpur, India).

## Structure
- `index.html` — the website
- `support.js` — runtime required by index.html (keep next to it)
- `assets/` — photo, CV page images and CV PDF

## Publish with GitHub Pages
1. Create a new repository and upload all files in this folder (keep the folder structure).
2. Go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`.
3. Your site will be live at `https://<username>.github.io/<repo>/`.

Note: open via a web server or GitHub Pages — opening index.html directly from disk may block some scripts in certain browsers.
